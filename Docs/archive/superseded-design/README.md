# Superseded design documents (archived 2026-09-27)

These files described earlier visual directions for Foreman: the charcoal/cream palette, the "UI/UX redesign" pass, the voice-page visual spec, and the agent skill's example tokens. They are kept as a record of past decisions only.

**They are not authoritative.** The design authority is [`DESIGN_SYSTEM.md`](../../../DESIGN_SYSTEM.md) at the repository root. Do not apply any colour, typography, layout, component or interaction rule from these files, including their "do not change" and "do not touch" restrictions on visual design.

Functional content that still applies (business rules, safety rules, data flow) was kept in the live specs under `Prompts/` and `New Docs ( scope )/`, and is summarised in `DESIGN_SYSTEM.md` §15.
